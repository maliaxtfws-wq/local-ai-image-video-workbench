# 工作流来源

视频 API 工作流参考 [Comfy-Org/workflow_templates v0.11.48](https://github.com/Comfy-Org/workflow_templates/tree/v0.11.48) 的 H3 文生视频、图生视频模板；在本工作台中加入固定输入绑定、画幅设置、首帧缩放与视频续接。新版图片 API 图亦参考 Comfy-Org 的 Qwen Image 2.1 模板。相关模板版权归 Comfy Org，附[原始 MIT 许可](LICENSE-Comfy-Org.txt)。

旧版图片工作流使用 Qwen Image / Edit 与 ComfyUI-GGUF 节点；仓库只提供工作流描述和工作台调用代码，不附节点实现、模型权重或示例人物照片。ComfyUI、Ollama、FFmpeg、模型及其权重各自遵循原项目的许可。
